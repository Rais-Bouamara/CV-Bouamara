# CV Bouamara Raïs

Site CV statique, en français, construit sans dépendance ni étape de compilation.

## Développement local

Ouvrir `index.html` dans un navigateur. Les styles responsive et d’impression
sont intégrés à la page.

## Publication sur GitHub Pages

Le workflow `.github/workflows/pages.yml` publie automatiquement le site à
chaque push sur `main` et peut aussi être lancé manuellement depuis l’onglet
**Actions**. Dans les paramètres du dépôt, sélectionner **Settings → Pages →
Build and deployment → GitHub Actions** comme source de publication.
